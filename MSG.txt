feat(ui): shared visualization and feedback components

Task 3 of the UI/UX redesign: the reusable pieces the Lab, lesson diagram,
landing hero and Compare will all draw with. Nothing here is wired to a screen
yet, so the shipped bundle is unchanged.

Visualization
  NodeShell gives every component one box, one status grammar and one shape.
  Status is never colour alone: each of idle/active/done/skipped/fault changes
  the border style, the background, an icon AND a word, so the pipeline reads in
  greyscale, to a colour-blind viewer, and to a screen reader. "Skipped" is
  dashed rather than tinted, because "not on this path" is a different statement
  from "not started yet".

  Six nodes: CpuNode, VirtualAddressNode, TlbNode, PageTableNode, FrameNode,
  RamNode. MemoryPipeline composes them in hardware order and decides layout and
  emphasis only - which box is lit, which are dimmed - so a learner meets the same
  six boxes in the lesson, the Lab, Compare and the landing page. MemoryRequest is
  the single travelling element the brief allows, and it does not travel under
  reduced motion.

Feedback
  StatusBadge, ExplanationCard, EmptyState, Skeleton, InlineError.
  EventExplanation answers State / What happened / Why / Next, and carries
  aria-live="polite" so a screen-reader user who presses Step is actually told
  what happened. Its PresentedEvent type is declared next to the component, so an
  event that cannot answer all four questions is a compile error rather than a
  blank panel in production. EventTimeline scrolls inside a bounded box and is
  walkable in both directions.

THE RULE these files obey: a component paints a fact, it never derives one. No
node splits an address, decides a hit or a miss, or computes a frame. Every value
arrives as a prop read off an engine event or engine state elsewhere, so the Lab
and the lesson cannot disagree with the engine or with each other.

Also adds usePrefersReducedMotion and the reveal spec, needed now because an
unconditional travel animation is not allowed to ship first and wait for Task 14.

Gates: tsc pass, build pass, bundle size unchanged.
